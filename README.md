# MyDigit 数码之家自动签到

一个用于 [数码之家](https://www.mydigit.cn) 论坛的 Python 自动签到脚本。

## 功能特性

- 自动登录数码之家论坛
- 自动完成每日签到
- 使用 Session 保持登录状态
- 支持安全提问验证

## 环境要求

- Python >= 3.10
- requests >= 2.32.5

## 安装

1. 克隆或下载本项目

2. 使用 uv 安装依赖：

```bash
uv sync
```

或者使用 pip：

```bash
pip install requests
```

## 配置

在 `main.py` 文件中填写以下配置信息：

```python
# ====== 配置信息（请填好自己的） ======
USERNAME = ""      # 你的数码之家用户名
PASSWORD = ""      # 你的数码之家密码
QUESTION_ID = "0"  # 安全提问 ID（0 表示未设置安全提问）
ANSWER = ""        # 安全提问答案（如果没有设置则留空）
```

### 安全提问 ID 对照表

| ID | 问题 |
|----|------|
| 0 | 未设置安全提问 |
| 1 | 母亲的名字 |
| 2 | 爷爷的名字 |
| 3 | 父亲出生的城市 |
| 4 | 您其中一位老师的名字 |
| 5 | 您个人计算机的型号 |
| 6 | 您最喜欢的餐馆名称 |
| 7 | 驾驶执照最后四位数字 |

## 使用

配置完成后，直接运行：

```bash
python main.py
```

或者使用 uv：

```bash
uv run main.py
```

## 实现流程

1. 访问首页获取初始 Cookie
2. 请求登录页面获取 `loginhash` 和 `formhash`
3. 提交登录请求完成登录
4. 访问签到页面获取签到所需的 `formhash`
5. 发送签到请求完成签到

## 注意事项

- 请妥善保管你的账号密码，不要将包含密码的代码提交到公共仓库
- 建议配合定时任务（如 Linux 的 crontab 或 Windows 的任务计划程序）使用，实现自动定时签到
- 脚本中设置了 5 秒延迟，请根据网络情况适当调整 `DELAY_TIME`
