# MyDigit 数码之家自动签到

[数码之家](https://www.mydigit.cn) 论坛的 Python 自动签到脚本，提供两个版本：

| 版本 | 文件 | 适用场景 |
|------|------|----------|
| 青龙版 | `mydigit_sign_ql.py` | 青龙面板 / 定时任务，环境变量配置，支持多账号 |
| 本地版 | `main.py` | 本机手动运行，账号直接写在源码中 |

## 功能特性

- 自动登录数码之家论坛并完成每日签到
- 支持安全提问验证
- 青龙版支持多账号、会话缓存复用、请求重试与失败隔离
- 青龙版可调用内置 `notify.py` 推送签到结果

## 青龙面板部署

`mydigit_sign_ql.py` 为单文件脚本，仅依赖 `requests`（青龙镜像已内置），配置全部通过环境变量注入。

### 1. 添加脚本

将 `mydigit_sign_ql.py` 上传到青龙脚本目录（如 `/ql/data/scripts/`），或在面板「脚本管理」中新建同名脚本并粘贴内容。

### 2. 配置环境变量

多账号模式（推荐）：

| 变量名 | 值示例 | 说明 |
|--------|--------|------|
| `MYDIGIT_ACCOUNTS` | `user1#pass1#0&user2#pass2#2#答案2` | 每个账号为 `用户名#密码#安全提问ID#答案`，账号之间用 `&` 或换行分隔，后两项可省略 |

单账号模式：

| 变量名 | 说明 |
|--------|------|
| `MYDIGIT_USERNAME` | 用户名 |
| `MYDIGIT_PASSWORD` | 密码 |
| `MYDIGIT_QUESTION_ID` | 安全提问 ID，默认 `0` |
| `MYDIGIT_ANSWER` | 安全提问答案，默认空 |

可选变量：

| 变量名 | 默认值 | 说明 |
|--------|--------|------|
| `MYDIGIT_USE_CACHE` | `true` | 是否复用会话缓存 |
| `MYDIGIT_DELAY` | `2` | 登录后等待秒数 |
| `MYDIGIT_NOTIFY` | `true` | 是否调用青龙 `notify.py` 推送结果 |
| `MYDIGIT_RETRY` | `3` | 单次请求重试次数 |

> 密码中包含 `#` 或 `&` 时会被当作分隔符截断，此类账号请改用单账号变量配置。

### 3. 创建定时任务

| 字段 | 值 |
|------|-----|
| 命令 | `task mydigit_sign_ql.py` |
| 定时规则 | `17 7 * * *`（每天 07:17，可按需调整） |

### 青龙版特性

- 多账号顺序执行，单账号异常隔离，互不影响
- 会话缓存复用（脚本目录下 `.mydigit_cache/`），失效则自动重新登录
- 自动识别「签到成功」「今日已签」两种正常结果
- 兼容青龙内置 `notify.py`；未安装时自动跳过推送
- 全部成功或已签到返回退出码 `0`，存在失败账号返回 `1`，便于青龙标记任务状态

## 本地运行

### 环境要求

- Python >= 3.10
- requests >= 2.32.5

### 安装

```bash
uv sync
```

或使用 pip：

```bash
pip install requests
```

### 配置

在 `main.py` 中填写账号信息：

```python
USERNAME = ""      # 你的数码之家用户名
PASSWORD = ""      # 你的数码之家密码
QUESTION_ID = "0"  # 安全提问 ID（0 表示未设置安全提问）
ANSWER = ""        # 安全提问答案（如果没有设置则留空）
```

### 运行

```bash
uv run main.py
# 或
python main.py
```

### 安全提问 ID 对照表

| ID | 问题 |
|----|------|
| 0 | 未设置安全提问 |
| 1 | 母亲的名字 |
| 2 | 爷爷的名字 |
| 3 | 父亲出生的城市 |
| 4 | 您其中一位老师的名字 |
| 5 | 您个人计算机的型号 |
| 6 | 您最喜欢的餐馆名称 |
| 7 | 驾驶执照最后四位数字 |

## 实现流程

1. 访问首页获取初始 Cookie
2. 请求登录页面，提取 `loginhash` 与 `formhash`
3. 提交登录表单完成登录
4. 访问签到页获取签到所需的 `formhash`
5. 请求签到接口完成签到，并解析返回文本

## 注意事项

- 请勿将账号密码提交到公共仓库。青龙版密码仅通过环境变量传入，不落盘；本地版请自行确保 `main.py` 不被提交
- `.mydigit_cache/` 存放登录 Cookie，已在 `.gitignore` 中排除，请勿手动提交
- 数码之家对游客同样返回签到页与 `formhash`，脚本以页头是否存在 `action=logout`（或「欢迎您回来」）判定登录态
- 若站点触发验证码或安全提问校验，脚本无法自动通过，会在日志中输出具体失败原因
- 青龙版登录后默认等待 2 秒，可通过 `MYDIGIT_DELAY` 调整
